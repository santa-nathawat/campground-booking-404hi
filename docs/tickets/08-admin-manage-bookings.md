# 08: Manage bookings as administrator

**Status:** Approved; not started.
**Blocked by:** [03](03-admin-create-campgrounds.md), [05](05-read-bookings.md), [06](06-edit-bookings.md), [07](07-delete-bookings.md)

Administrators can manage anyone's bookings without weakening ordinary-user privacy.

## Done when

- [ ] List and inspect bookings from all users.
- [ ] Edit campground/dates or delete any booking. Keep its owner fixed.
- [ ] Apply the same date and duration rules to administrator edits and personal bookings.
- [ ] Administrators create bookings for themselves only, not on behalf of other users.
- [ ] Preserve ordinary users' own-only access and deny unauthenticated requests.
- [ ] Test the user A/user B/administrator access matrix through HTTP. Add matching Postman scenarios.
